# «Английский с Быничем» — ТЗ на первую версию (MVP v1)

> Демо: https://enikey87.github.io/mu-en/
>
> Шуточный интерактивный лендинг школы английского языка для детей.
> Бынич — бык с добрыми глазами — учит английские слова, которые начинаются на «moo»,
> и произносит их как «муууууун», «мууууууд» через Web Audio, с смешной интерактивной анимацией.

---

## 1. Общее описание

Одностраничный статический сайт без бэкенда. Персонаж Бынич (векторный SVG-бык)
«преподаёт» английский по авторской методике: настоящие английские слова — это только
слова на «moo», и произносить их нужно протяжным мычанием.

Тон продукта: добрая абсурдная комедия. Детям — смешно и интерактивно,
родителям — пасхалки для взрослых.

## 2. Цели v1

- Развеселить и удивить: концепт должен считываться за 10 секунд.
- Дать пощупать ядро идеи: клик → мычание-озвучка + анимация Бынича.
- Собрать обратную связь для решения, развивать ли проект дальше.

## 3. Аудитория

- Основная: дети 5–10 лет (играют на планшете/телефоне родителей).
- Вторичная: взрослые (шарят ссылку ради шутки, находят easter eggs).

## 4. Стек и ограничения

| Параметр | Решение |
|---|---|
| Тип | Статический одностраничник |
| Сборка | Vite |
| Язык | TypeScript, без UI-фреймворков (ванильный DOM) |
| Стили | Обычный CSS (один файл), CSS keyframes для анимаций |
| Аудио | Web Audio API, без внешних сэмплов — звук синтезируется |
| Микрофон | Web Audio API: анализ звука (тон, спектр, громкость), без распознавания речи и без сети |
| Графика | Инлайн-SVG (Бынич рисуется руками, без растровых картинок) |
| Бэкенд | Нет. Никаких форм, заявок, трекеров, внешних запросов |
| Деплой | GitHub Pages (main → pages) |

## 5. Функциональные требования

### F1. Hero-секция
- Заголовок «Английский с Быничем», слоган «От муу до fluency».
- SVG-Бынич крупно, idle-анимация (неторопливое жевание, моргание).
- Кнопка «Познакомиться» → Бынич произносит приветствие:
  «Мууу! Ай эм Бынич» (озвучка движком F4).

### F2. Живой Бынич
- Глаза следят за курсором/пальцем (добрые глаза — обязательное требование).
- Во время озвучки: щёки надуваются, хвост машет в темп мычанию,
  голова покачивается.
- При длинном мычании — лёгкая тряска страницы (CSS class, снимается по окончании).

### F3. Словарь «Moo-words» (ядро v1)
Карточки слов, минимум 6:
`moo, moon, mood, moose, moot, moor` — с переводом и транскрипцией «по-быньочьи»
(`муу, мууууун, мууууд, муууус, мууут, муууур`).
- Клик по любому месту карточки (кроме кнопки «мууу»): озвучка движком F4 + анимация F2.
  Карточка подсвечивается при наведении и у слова появляется значок-динамик. Галочку такой клик **не** даёт.
- Галочка «выучено» ставится только за настоящее «мууу» в микрофон (F10).
- Хвостовая согласная (n/d/t/r) имитируется коротким «носовым» акцентом в конце мычания.

### F4. Аудио-движок мычания (Web Audio, синтез)
- Голос: осциллятор (triangle + лёгкий sawtooth) через lowpass-фильтр (форманта «у»,
  срез ~400–700 Гц), вибрато LFO ~5–6 Гц.
- Огибающая: мягкая атака «м» (короткий буст амплитуды), длинное «уууу»,
  финальный согласный — краткое (50–80 мс) сужение фильтра + провал gain.
- Длительность «уууу» пропорциональна длине слова; случайный лёгкий jitter питча,
  чтобы мычания не звучали одинаково.
- Отдельный режим «зажми и мычи»: пока кнопка/сам Бынич зажаты — тянется «мууууу»
  (gain держится), отпускание = окончание.

### F5. Moo-DJ пады
- Секция-семплер: 6 падов (слова из F3).
- Клик по паду: озвучка + подпрыгивание пада + реакция Бынича.
- Комбо (3+ падов за 2 сек): ускоренное мотание хвостом и тряска страницы.

### F6. Секция отзывов
2–3 шутливых отзыва (корова Зорька: «до Бынича я вообще не разговаривала»,
телёнок: «нууууу» и т.п.). Статика, без карусели.

### F7. Тариф «Moo-t Premium» (easter egg)
- Плашка «5 сена/мес», кнопка «Оплатить» — при клике Бынич возмущённо мычит
  и ничего не покупается.

### F8. FAQ
3–4 шутки в формате вопрос–ответ. Обязательно: «А если слово не начинается на "moo"?» —
«Тогда это не английское слово».

### F9. Футер
«© Бынич. Все права защищены рогами.»

### F10. Микрофонный экзамен «мууу»
Галочка «выучено» ставится только за мычание в микрофон — слово вслух не считается.
- В каждой карточке — отдельная кнопка «Сказать «мууу»».
- Детектор (Web Audio, без сети и без распознавания речи) требует одновременно:
  громче фона (порог калибруется по комнате за первые ~0,4 с), низкий тон
  70–460 Гц, гласную «у» по спектру (центроид ≤ 850 Гц, F2 ≤ 1300 Гц, энергия
  в низах) и протяжность ≥ 0,8 с; окно попытки ~4,2 с.
- Во время прослушивания: пузырь «Слушаю…», наклонённая голова Бынича,
  пульсирующая кнопка и му-метр (шкала громкости + полоска протяжности).
- Успех: галочка, конфетти, радостное мычание и слово вслух, прогресс +1,
  когда выучены все слова — диплом. Осечка: озадаченный Бынич и подсказка («Тихо»,
  «Это было не мууу», «Тяни дольше»).
- Фолбэк: если микрофон запрещён, занят или его нет — кнопка переходит в режим
  «Зажми и мычи»: удержание ≥ 1 с засчитывает слово. Режим запоминается на сессию.
- Микрофон слушает только во время попытки и сразу выключается; ничего не
  записывается и не отправляется. Нужен защищённый контекст (GitHub Pages — HTTPS).

## 6. Нефункциональные требования

- Адаптив: от 360 px до десктопа; touch-события для «зажми и мычи».
- Аудио-контекст активируется по первому пользовательскому действию (autoplay policy).
- Работает в актуальных Chrome/Safari/Firefox, iOS Safari обязателен.
- Ноль внешних сетевых запросов после загрузки.
- Микрофон — только по явному нажатию кнопки в карточке; поток освобождается по окончании попытки.
- Вес страницы < 200 КБ, без шрифтовых CDN (системный стек шрифтов).

## 7. Не входит в v1 (бэклог)

- Moo-inator: «муу-переводчик» произвольных слов.
- Дуэль наставников (Гусак и слова на "honk").
- Mood-o-meter (ползунок настроения, меняющий питч мычания).
- PWA, i18n, аналитика, реальная оплата.

## 8. Этапы работ

1. Скелет лендинга: секции F1, F3, F6–F9 со статичным Быничем.
2. Аудио-движок F4 + интеграция в карточки.
3. Живой Бынич F2 (глаза, реакция на озвучку, зажатие).
4. Пады F5 и комбо-эффекты.
5. Микрофонный экзамен F10: детектор «муууу», му-метр, фолбэк «зажми и мычи».
6. Полировка: адаптив, производительность, деплой на GitHub Pages.

## 9. Критерии приёмки

- [ ] Клик по любому месту карточки (кроме кнопки «мууу») → слышимое протяжное «муууу…»
      с финальным акцентом, Бынич анимируется (щёки, хвост, покачивание).
      Карточка подсвечивается при наведении, галочка при этом не появляется.
- [ ] Сказанное в микрофон громкое протяжное «муууу» ставит галочку: карточка
      подсвечивается, играет конфетти, прогресс растёт, когда выучены все слова — диплом.
- [ ] «Аааа», «ииии», шум, тихое или короткое мычание галочку не ставят —
      Бынич озадаченно мычит и подсказывает, чего не хватило.
- [ ] Во время прослушивания видно му-метр и пузырь «Слушаю…»; микрофон отпускается
      сразу после вердикта или повторного нажатия.
- [ ] При отказе в доступе к микрофону кнопка переходит в «Зажми и мычи»,
      удержание ≥ 1 с засчитывает слово, короткое — нет.
- [ ] Глаза Бынича следят за курсором на десктопе и за пальцем на тач-устройствах.
- [ ] «Зажми и мычи»: мычание длится ровно столько, сколько держат кнопку.
- [ ] Комбо из 3 падов вызывает тряску страницы.
- [ ] Страница открывается и играет звук с телефона (iOS Safari) по первому тапу.
- [ ] Детектор проходит `npm run moo:probe`: 10 сценариев (мууу взрослого и ребёнка,
      обманки, тишина) с ожидаемыми вердиктами.
- [ ] В сети отсутствуют запросы к сторонним доменам; сборка деплоится на GitHub Pages.
